# Branchly 思维导图

一个零前端依赖、可直接运行的嵌套块视图思维导图 Web 项目。项目按照 `plan.pdf` 中的手绘需求实现：父节点纵向贯穿其所有子项，子节点在右侧按同级关系上下切分，下一层继续向右嵌套切分。同时提供键盘操作、右键菜单、缩放自适应展开和 JSON 后端持久化。

## Windows / Android 客户端

`cross-platform/` 包含基于 Tauri 2、Rust、SQLite 和同一套块视图前端开发的跨平台版：

- Windows 与 Android 共用全部导图功能和交互。
- 编辑内容以 SQLite WAL 事务立即保存，并维护恢复点和独立物理备份。
- 图片保存在本地文件系统，按 SHA-256 去重同步，不进入数据库正文。
- 可选云同步使用持久化 outbox、版本条件更新、幂等操作和显式冲突副本。
- 云凭据通过本地工作空间密码派生的密钥加密保存，访问令牌自动轮换。

本机按项目要求不构建原生应用。完整架构、开发环境、性能预算和 GitHub 构建说明见
[`cross-platform/README.md`](cross-platform/README.md)。

## 启动

```bash
npm start
```

浏览器打开 <http://localhost:4173>。

工作空间由后端密码保护。固定访问密码配置在服务端，登录后使用仅 HTTP 可见、SameSite 严格模式的会话 Cookie；退出或服务重启后可重新登录。

## 主要操作

- 单击节点选中；双击或按 `F2` 修改标题和备注。
- 选中节点后，节点上方、下方和右侧的 `+` 分别添加同级或子节点。
- `→` 创建子节点，`←` 返回父节点；在中心节点按 `←` 可在左侧建立新的中心主题。
- `↑` / `↓` 在同级节点之间切换，`Enter` 创建下方同级节点。
- 空格折叠或展开分支，`Delete` 删除节点。
- 拖动画布平移，滚轮缩放；缩放时会根据节点的可读尺寸自动显示更深层级。
- 视野平移采用 5px（触控 8px）动作阈值：短按仍是点击，超过阈值才开始平移；可以直接从块内容或画布空白处开始移动，画布内的浏览器原生元素拖拽被禁用，不会再出现整棵导图的幽灵拖影。
- 支持搜索、聚焦、自动布局、撤销/重做、配色、JSON 导入与导出。
- 描述支持 `+++重点内容+++` 语法，渲染时显示为粗体和下划线；编辑窗口提供实时预览，并可用 `Ctrl/Command + Enter` 保存。
- 每个块支持最多 100 条独立标注，用于补充解释、例子、延伸知识和易错点；标注支持新增、编辑、删除、撤销、搜索和 `+++重点+++` 语法，块上显示“注＋数量”。
- “竖直切分”会保留当前块作为左侧父块，在右侧插入新块，并把当前块原有的整棵孩子子树交给右侧新块。
- “水平切分”会保留当前块作为上方块及其全部孩子，同时在下方创建一个同父兄弟块；中心块切分时会自动创建共同父级。
- “重新归属”可将所选块连同全部后代移动到另一个现有块下；交互会标出合法目标，并阻止归属到自身、后代或当前父块造成循环或无效移动。
- 块之间支持独立“关系边”：右键块选择“添加关系”后可拖动画布、滚轮缩放并点击目标，也可以从选中块左侧的 `↝` 手柄直接拖到目标；在选中块正文长按约 480ms 后拖动同样可创建关系，立即移动则仍是画布平移。
- 关系边支持主题、500 字描述以及 A→B、A←B、A↔B、A—B 四种类型；同一块可连接多个块，同一对块可重复建立多条不同关系。关系使用块视图上下方的独立分轨布线，点击轨道标签可编辑或删除。
- 关系边最多保存 500 条；上下相邻块使用局部短直线，相邻列使用列间沟槽，只有跨列或可能穿过块的关系才使用外围分轨。工具栏“关系边”可临时隐藏/显示边以整理复杂画布；全局搜索同时匹配边主题和描述，悬浮或键盘聚焦边标签时会高亮两个端点。
- 可为任意块上传多张 JPEG、PNG、WebP、GIF 或 AVIF 图片；普通块在最右侧显示图片数量，大块在右下角显示数量。后端会校验实际文件签名，不只信任浏览器声明的 MIME 类型。
- 点击图片数量块可打开该节点的图库，支持大图浏览、前后切换、下载原图和移除图片；单张图片上限为 12 MB。

## 数据

服务端使用 Node.js 内置 HTTP 模块，不依赖数据库。导图通过 `GET /api/map` 和 `PUT /api/map` 读写。前端变更先同步到服务端内存队列，服务端每 5 秒以原子替换方式保存到 `data/mindmap.json`，同时维护 `data/mindmap.json.bak` 滚动备份；主文件损坏时会自动从有效备份恢复，正常关闭时还会执行一次最终落盘。图片本体保存在 `data/uploads/`，导图 JSON 仅保存图片元数据。移除的图片先进入 `data/image-trash/`，从撤销历史恢复引用时会自动还原，超过七天的回收文件由后端清理。

关系边保存在文档根级 `relationships` 数组中，与决定块布局的父子树分离。重新归属不会改变关系端点，因为端点由稳定节点 ID 引用；删除节点或整棵子树时，引用其中任意节点的关系会同步删除，避免悬空边。
