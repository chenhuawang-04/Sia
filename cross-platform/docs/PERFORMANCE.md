# 性能预算

发布候选版本需要在一台 8 GB Windows 11 设备和一台 4 GB Android 设备上记录以下指标。
这些是发布门槛，而不是理想值：

| 指标 | Windows | Android |
|---|---:|---:|
| 空白启动到可交互 p95 | ≤ 1.8 s | ≤ 2.5 s |
| 23 块示例导图常驻内存 | ≤ 120 MB working set | ≤ 150 MB PSS |
| 后台无同步时 CPU | < 1% | 不持有 wake lock |
| 500 块布局 p95 | ≤ 40 ms | ≤ 65 ms |
| SQLite 本地保存 p95 | ≤ 35 ms | ≤ 60 ms |
| 5000 块文档载入 | ≤ 1.2 s | ≤ 1.8 s |
| 增量同步空闲流量 | 0 B | 0 B |

测试时必须区分系统 WebView 的共享内存和应用私有内存，并同时记录设备、系统、WebView
版本、文档规模与图片数量。任何超过预算的发布需要附带 profile，而不能仅以“功能正常”
豁免。
